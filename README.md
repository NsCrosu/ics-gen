这是一个快捷将教务网站课表信息转为 .ics 日程文件的工具，旨在减少对学习通在线查询的依赖。  
由[此项目](https://github.com/junyilou/python-ical-timetable)（python-ical-timetable）启发，并在其基础上进行修改适配。  
额外参考了[此项目](https://github.com/qwqVictor/CQUPT-ics) （CQUPT-ics）。  

本仓库附带了一个仅适用于 USTL 的教务数据源转换器，用于快速将教务提供的 json 数据源转换为 python 程序需要的格式。  
程序使用 .NET 编写。由于代码已遗失，本仓库仅做备份用途。有需要可以自行使用 `dnSpy` 等软件进行反编译工程以获取代码。
